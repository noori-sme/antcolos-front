# Implementation plans

`NN-<slug>.md`, numbered from `01`. The next plan is the highest NN + 1. Created by `/feature`
from `.claude/skills/feature/plan-template.md`.

A plan is the hand-off between sessions: keep its status block (`Status`, `Phase`, `Updated`)
current so a fresh session can resume after `/clear`. No production code is written before the
user approves the plan.

Frontend plan numbers are independent of the backend's `../antcolos/docs/plans/`.
