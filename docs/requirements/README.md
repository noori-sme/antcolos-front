# Frontend requirements

One file per feature: `<feature>.md`, created with `/requirements` from
`.claude/skills/requirements/template.md`.

These describe **screens, states, permissions, and the mapping to backend endpoints**. Business
rules and the API contract live in the backend (`../antcolos/docs/requirements/`). Link to them
and don't copy them.

Status line on top: `draft` → `agreed` (no open design questions) → `implemented`.
